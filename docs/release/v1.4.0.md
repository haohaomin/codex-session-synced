# Codex Synced v1.4.0

[English](https://github.com/renhao12356578/codex-session-synced/blob/v1.4.0/docs/release/v1.4.0-en.md) | 中文

新增 **macOS 实验性「对话诊断与修复」**，处理原始对话文件仍在、读取入口指向旧分支而导致后续消息不可见的情况。

**平台差异：新增入口修复与分页文件保护仅在 macOS 提供。Windows 1.4.0 保留 1.3.0 原有功能，仅同步版本号与安装包。**

## 下载

- `Codex-Synced-macOS-1.4.0.dmg`：包含新增「对话修复」页面。
- `Codex-Synced-Windows-x64-1.4.0.msi`：Windows 安装包，不包含新增入口修复。
- `Codex-Synced-Windows-x64-1.4.0.zip`：Windows 便携目录。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

macOS 包暂未经过 Apple 公证，安装提示见 README。

## 新增与改进

- 独立的只读扫描、逐条预览与确认，不混入原有侧边栏一键修复。
- 区分逻辑对话 ID 和物理分支 ID，沿 `history_base` 检查唯一后继链、序号及字节边界；不根据文件修改时间猜测入口。
- 多末端、缺失文件、循环、未知格式、偏移不一致及数据变化时，拒绝自动修复。
- 必须先退出 Codex Desktop / CLI。SQLite Backup API 包含已提交 WAL 数据；备份原始分支文件，先在数据库副本试写。
- 真实库仅修改选中对话的 `rollout_path`，保留所有其他字段，不改写历史库或正文。
- 撤销仅反向修改入口，不覆盖整库；目标记录或文件出现后续变化时阻止撤销。
- macOS 原有 Provider 修复不再改写分页 JSONL 首行，避免破坏后继分支字节偏移。
- 新增 21 个回归测试，连同原有测试共 34 个；发布流程增加 macOS 测试门槛，附件上传完成后再公开 Release。

## 重要验收边界

该功能仍为实验性。自动检查包括原文件 SHA-256、分支边界、非入口字段不变和 SQLite 完整性；**数据库副本试写不等于在隔离客户端中验证读取**。

尚未自动验证官方 `thread/read` / 分页接口的逐条正文一致性，以及桌面重新打开和重启后的持久性。修复后请重新打开原对话，检查内容、顺序、遗漏、重复与项目归属，再正常退出并重启 Codex 复核。“入口已修复”不代表全部验收完成。

偏移异常（包括相差 50 字节的情况）仅报告，不自动改写。备份包含私人对话，位于 Codex Home 下的 `history-entrypoint-backups/`，不自动清理；不宣称跨数据库原子快照。
