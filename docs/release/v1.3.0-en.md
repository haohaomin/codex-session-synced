# Codex Synced v1.3.0

English | [中文 ->](https://github.com/renhao12356578/codex-session-synced/blob/main/docs/release/v1.3.0.md)

This update supports the current Codex Desktop local thread layout and focuses on history that remains on disk but becomes invisible after a provider switch.

## Highlights

- Selects the active state database across `.codex/state_*.sqlite` and `.codex/sqlite/state_*.sqlite`, including WAL and SHM activity.
- Aligns both active and archived interactive threads in SQLite and rollout session metadata.
- Keeps archived and internal thread records when rebuilding `session_index.jsonl`, with unique IDs.
- Updates both `threads.title` and the current `threads.name` field during title repair.
- Repairs timezone-migration rows where `created_at` is later than `updated_at`.
- Detects tool-call fragments in generated titles and recovers a clean title from the preview or first user message.
- Streams rollout first-line replacement so large conversations are not loaded fully into memory.
- Extends the Finder layout timeout to make DMG packaging more reliable on slower machines and CI runners.

## Safety

Repairs still create a restorable backup first. Rollout changes replace only the first `session_meta` line and preserve all message-body lines.
