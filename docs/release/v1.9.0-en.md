# Codex Synced 1.9.0

## Software update discovery

- macOS and Windows now provide **Settings → Software Update**, with manual checks, opt-in launch checks (off by default), installed/latest versions and plain-text release notes.
- Checks use the fixed `haohaomin/codex-session-synced` GitHub stable-release endpoint and validate numeric versions, the release page and matching platform assets.
- Drafts, prereleases, invalid versions, missing/duplicate assets and unexpected sources are rejected. Requests are time- and size-limited and do not send local tokens, chats or Provider configuration.
- Checks never download packages. Automatic errors are quiet; manual errors are visible and never presented as “up to date”.
- After confirmation, open that version's release page. Choose the macOS DMG or Windows x64 MSI; portable users should extract ZIPs into a new directory.

## Boundaries

This is not automatic installation. Independent updater signatures are not yet available; SHA256SUMS are not signatures. The app does not download/execute installers, terminate processes, overwrite the application or modify `.codex`, messages, databases or Provider configuration. Finish repairs and quit Codex Synced normally before installing. Keep the old app and backups, then verify the version and data after relaunch. Opening a page does not mean installation succeeded.

Conversation repair algorithms are unchanged. Signed installation, automatic replacement, restart handshakes and rollback remain future work.

## Validation

Local verification: 49 Swift tests and the macOS Release build passed; 58 Windows updater assertions and WPF Release cross-compilation passed. The release workflow additionally gates publishing on Windows self-tests, updater tests and Swift tests. Windows update UI still requires real-device verification; build/tests do not prove data preservation after a real installation.
