# Codex Synced v1.3.0

[English ->](https://github.com/renhao12356578/codex-session-synced/blob/main/docs/release/v1.3.0-en.md) | 中文

本次更新适配新版 Codex Desktop 本地会话结构，重点修复“会话文件仍在，但切换 Provider 后普通历史或归档历史不可见”的问题。

## 主要变化

- 同时检查 `.codex/state_*.sqlite` 与 `.codex/sqlite/state_*.sqlite`，结合数据库、WAL 和 SHM 修改时间选择当前状态库。
- 跨 Provider 对齐覆盖未归档和已归档的普通会话，同时更新 SQLite 与 rollout 首行 metadata。
- 重建 `session_index.jsonl` 时保留归档与内部线程记录，并去除重复 ID。
- 兼容新版 `threads.name` 字段，标题修复会同步更新 `title` 与 `name`。
- 检测并修复 `created_at` 晚于 `updated_at` 的时区迁移异常。
- 识别标题中的工具调用残片，并从会话预览或首条用户消息恢复干净标题。
- rollout 首行改为流式替换，避免大型会话占用过多内存。
- 延长 DMG Finder 布局阶段的超时时间，提高慢速机器和 CI 环境下的打包稳定性。

## 安全性

修复前仍会创建可恢复备份。rollout 修复只替换首行 `session_meta`，不会修改后续消息正文。
