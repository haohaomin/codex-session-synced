# Codex Synced v1.4.0

Adds experimental **Chat Diagnosis & Repair for macOS** for conversations whose original files still exist but whose entrypoint points to an older branch.

**Platform scope:** the new repair page and paginated-header protection are macOS-only. Windows 1.4.0 retains the functionality of 1.3.0 with refreshed version metadata and packages.

## Downloads

- `Codex-Synced-macOS-1.4.0.dmg`: includes Chat Repair; not Apple-notarized.
- `Codex-Synced-Windows-x64-1.4.0.msi`: Windows installer, without the new entrypoint repair.
- `Codex-Synced-Windows-x64-1.4.0.zip`: Windows portable directory.
- `SHA256SUMS.txt`: package checksums.

## Changes

- Separate read-only scanning, per-chat previews and explicit confirmation.
- Follow original `history_base` links using logical and physical IDs, checking a unique successor chain, ordinals and byte boundaries. Never select a tip by modification time.
- Block ambiguous tips, missing files, cycles, unsupported formats, offset discrepancies and stale previews.
- Require Codex Desktop/CLI to exit. Back up committed WAL content with SQLite Backup API, preserve source files, and trial the change on a database copy.
- Change only the selected `rollout_path`, preserving every other field, the history database and message files.
- Roll back only that entrypoint, never the whole database. Refuse rollback after target metadata or files change.
- Stop macOS Provider repair from rewriting paginated JSONL headers and invalidating inherited byte offsets.
- Add 21 regression tests, bringing the suite to 34. Release automation now runs macOS tests and publishes only after uploading assets.

## Acceptance limits

This feature is experimental. Automated checks cover source SHA-256, inheritance boundaries, preservation of non-entrypoint fields and SQLite integrity. **A database-copy trial is not isolated client-read verification.**

Official `thread/read` / paginated message-by-message equivalence and desktop reopen/restart persistence are not automatically verified. Reopen the original chat and inspect content, order, omissions, duplicates and project association; quit and restart Codex to check persistence. “Entrypoint repaired” does not mean full acceptance.

Byte-offset anomalies, including a 50-byte discrepancy, are reported without modification. Backups contain private conversations, remain under `history-entrypoint-backups/` in Codex Home, and are not auto-pruned. No atomic cross-database snapshot is claimed.
