# v1.6.0（开发中）

## 分页 Provider 第二阶段修复

本版本将分页 rollout 的 Provider 修复从普通侧边栏修复中拆出，避免只改 SQLite 元数据而留下错误的历史边界。

- 建立全局物理分支索引，验证唯一 lineage、父文件、末端、ordinal 和字节边界。
- 预测首行 Provider 改写的字节增量，重算后代 `history_base`、`thread_turns` 和 projection 偏移。
- 通过 SQLite Backup API 和唯一临时目录进行副本试写，正文保持原样。
- 真实写入采用旧值条件更新、首行 compare-and-swap、正文哈希和失败恢复。
- 增加多历史库、跨文件重复物理 ID、诊断展示和可注入运行状态检查。

## 当前发布边界

这是实施记录，不代表 v1.6.0 已发布。完成发布前仍需跑完整 Swift 测试、Release 构建，并在副本中验证 50 字节中间偏移、失败回滚以及 Codex 重启后的逐条读取。

详细顺序、禁止事项和验收标准见 [分页 Provider 自动修复实施方案](../paginated-provider-repair-plan.md)。
