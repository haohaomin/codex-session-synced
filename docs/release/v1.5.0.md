# Codex Synced v1.5.0

本版本聚焦于切换 Codex Provider 后的历史可见性，以及修复流程的安全边界。

## 新增与改进

- 将 Provider 诊断、分页风险提示、WAL 备份和验收边界统一到同一套预览流程。
- 普通格式 rollout 继续支持对齐到当前根级 Provider；分页 rollout 的首行仍保持原字节，不在未重算 `history_base` 前改写。
- 轻量备份保留活动数据库主文件、WAL、SHM，并用 SQLite Backup API 生成一致快照；覆盖存在的 `state_*`、`thread_history_*` 和 `logs_*` 数据库。
- 扫描会忽略明确的临时、修复残留和备份副本；未知 rollout 文件只阻断同目录会话，不影响无关目录。
- 待修复项和对话修复页面新增统一风险卡片，明确“元数据修复通过”与“客户端正文验收完成”的区别。
- 增加跨目录未知文件、忽略残留文件和备份边界回归覆盖。

## 仍需人工确认

分页 Provider 差异和任何字节偏移不一致仍会进入人工确认。应用不会拼接正文、重建 JSONL 或根据文件修改时间猜测分支。入口修复后仍需重新打开对话并重启 Codex，核对正文顺序、遗漏、重复和项目归属。

- macOS DMG 和 Windows MSI 由发布工作流生成。
