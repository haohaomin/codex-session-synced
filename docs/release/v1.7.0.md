# Codex Synced 1.7.0

本版本完成 Windows 与 macOS 的修复入口统一：

- Windows 新增「对话修复」页面，支持分页 lineage 只读诊断、最小 `rollout_path` 修复和安全撤销。
- Windows 分页 Provider 修复独立于普通 Provider 对齐，验证唯一物理分支链、`history_base`、`thread_turns` 和 projection 偏移后才允许确认写入。
- 分页写入使用 state/history SQLite Backup API 快照、rollout 副本试写、旧值 compare-and-swap、正文哈希和失败恢复。
- Windows 与 macOS 使用统一的风险分层：普通修复、分页可安全重算、需人工确认和重启后人工验收分别展示。
- README、英文 README 和 Windows 分页方案补充平台能力边界与验收要求。

安全边界：工具不拼接或重建消息正文，不修改 Token、API Key、Provider URL、项目归属或 Codex.app。通过文件哈希、SQLite 完整性和偏移校验只代表本地入口/元数据写入安全；修复后仍需重新打开并重启 Codex，逐条核对正文顺序、遗漏、重复和项目归属。

验证：Windows Release 编译与 `--self-test` 由 Windows CI 执行；macOS 的完整 Swift 测试和 DMG 构建由同一发布工作流执行。
