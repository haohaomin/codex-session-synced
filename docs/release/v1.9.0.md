# Codex Synced 1.9.0

## 新增应用更新入口

- macOS 与 Windows「设置 → 应用更新」支持手动检查、默认关闭的启动检查、当前/最新版本与纯文本发布说明。
- 固定读取 `haohaomin/codex-session-synced` 的 GitHub 稳定发布信息，按数字比较版本，校验发布页与对应平台资产的名称、上传状态、大小及下载地址。
- 拒绝草稿、预发布、非法版本、缺失/重复资产和未知来源；检查设置了超时与响应大小限制。不发送本地 GitHub token、对话或 Provider 配置。
- 检查不下载包；自动检查失败不弹窗，手动检查失败显示原因，不会误报“已是最新”。
- 用户确认后打开对应版本下载页。macOS 选择 DMG，Windows MSI 用户选择 x64 MSI，便携版用户将 ZIP 解压到新目录。

## 安全边界

这不是一键自动安装。现有发布没有独立更新签名，SHA256SUMS 不能替代签名。程序不下载/执行安装器、不结束进程、不覆盖应用，也不改写 `.codex`、会话正文、数据库或 Provider 配置。安装前请完成修复并正常退出 Codex Synced，保留旧应用与备份；重启后核对版本和数据。打开页面不代表安装成功。

本版本没有改变会话修复算法。签名更新、自动替换、重启握手与失败回滚留待后续实现。
